# Ascent concept images

Preview renders of R7: Ascent's models that the author approved (`docs/ASCENT.md`, "Art pipeline: Blender to Three.js").
Each is rendered by its Blender script with `-- --preview` into `tools/ascent/out/` (not in git) and copied here once the
author signs it off. Not used by the site and not part of the build.

| File | Script | What it shows |
| --- | --- | --- |
| `agent-front.png` | `tools/ascent/build_agent.py` | the robot agent from the front three-quarter view: the ivory head with the brass visor band, the antenna, the chest plate, the stubby arms, dark legs in ivory boots |
| `agent-behind-game-crop.png` | `tools/ascent/build_agent.py` | the robot from behind at the game camera's angle, cropped close: the hatch on the back of the head and the battery pack with its edge lines |
| `agent-behind-game.png` | `tools/ascent/build_agent.py` | the same view at the game camera's distance and field of view, the size the player sees it |

Approved 2026-10-27 (design A of three; the first renders read as flat, so this version adds the light that turns with the
camera, smooth shading and the raised plates). The renders have no fog, and the floor is plain: the level is not in them.
