# Inputs to confirm before writing

Ask for what is missing in one short message. Say the default you would use. Do not start until the starred ones are known. Read `docs/WRITING_GUIDE.md` first: the recipe for the kind decides which pictures and sources you need to ask for. Write the text using the orbit-voice skill (invoke it by name), then apply the layout recipe from docs/WRITING_GUIDE.md.

| Input                                                            | Default                               | Notes                                                                                                                                               |
| ---------------------------------------------------------------- | ------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------- |
| Kind*                                                            | none                                  | `blog`, `news`, `vlog`, `project`, `repo`, `game` or `app` (a project with `playUrl` and `appType`)                                                  |
| Title*                                                           | none                                  | Sentence case, one `*brass phrase*` at most; `seoTitle` (49 or fewer) if the plain title is over 49 characters                                      |
| Summary*                                                         | none                                  | 155 characters or fewer (hard limit 180). If the author gave none, propose one built only from what they gave, and mark it as a proposal            |
| Date                                                             | today (UTC, `date -u +%F`)            | Future = scheduled: hidden until the first build on or after it                                                                                     |
| Draft                                                            | `true`                                | `false` only when the author says it goes live                                                                                                      |
| Author*                                                          | `hunter-newton` (leave the field out) | AI-written = the writing agent's slug if its author file exists, else `author: r7`; never Hunter. Never write the agent's note or label                 |
| Tags                                                             | none                                  | Lowercase-hyphenated, at most 6, reuse existing ones                                                                                                |
| Picture + alt text                                               | none: IMAGE NEEDED marker, draft      | The hero (`featuredImage` or `cover`; the video for a vlog) and the body pictures the recipe asks for (screenshots, gallery). Files the author supplies, 16:9 ≥1280px for a hero, clean (no logos or text baked in); alt text for each. No hero on purpose: the reason, for `# heroless:` |
| Sources                                                          | none                                  | News: `sourceUrl`, `sourceName`. Any outside claim: the link it came from                                                                           |
| Recipe and form                                                  | the guide's recipe for the kind       | News, games post, project or app, vlog, long essay (`docs/WRITING_GUIDE.md`); MDX (blog only), Markdown or sections, from `templates/layouts/`       |
| Body                                                             | none                                  | The author's text, or a brief to write from. Markdown/MDX or sections, never both                                                                   |
| Vlog: YouTube id*, duration*                                     | none                                  | 11-character id, `m:ss` or `h:mm:ss`; chapters optional                                                                                             |
| Project: `status`*                                               | none                                  | `idea`, `building`, `shipped`, `paused`, `archived`                                                                                                 |
| Game / app: `playUrl`*, `appType`*, mode, aspect, controls, platforms, note, order | `embed`, `16:9`; `appType` `app` | https only. `appType` is `game` (Play) or `app` (Open), from `APP_TYPES`. Embedded: the host goes in `frame-src` in `public/_headers` and in `tests/headers.spec.js` (unless already there), and the app must allow framing by `https://r7orbit.io`. `link` needs none |
| Repo: `owner/name`*                                              | none                                  | Stats and README come from GitHub at build time; never typed                                                                                        |
| Featured                                                         | `false`                               | Only one post may be featured                                                                                                                       |

Do not ask for, or add: an email address, a newsletter, an RSS link, any profile link other than GitHub and YouTube.
