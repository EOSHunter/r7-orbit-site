# Final report

Keep it short. Use this order.

1. **Files:** every path created or edited (content, pictures, `public/_headers` if a game host was added). Nothing else changed.
2. **Front matter used:** the block, verbatim, with `draft` and `date` stated in words ("draft, not published", "scheduled for 2026-11-02").
3. **Verified:** each command run and its result (`check`, `lint`, `build`, `test:unit`, `test:e2e`, Lighthouse if run), the routes seen in `dist/`, the listings, sitemap and search checks, the no-leak check, the screenshot widths (375, 1280) and the console state.
4. **Not verified:** anything you could not run or see, and why. Say it plainly.
5. **Claims to check:** each statement you could not tie to a source the author gave or a link you opened. For R7 pieces written from sources, the link behind each claim.
6. **The author must:** upload a missing picture through `/admin` (and give its alt text), confirm a link, a video id or a play URL, review the text before it is credited to a person, set `draft: false` (or confirm the date), and add the game host to `public/_headers` if you did not.

Never push or merge: Orbit handles that.
