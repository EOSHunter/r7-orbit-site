# Newsletter issues

Mercury's weekly issues, one Markdown file per issue, named by the day it is sent: `issues/2026-11-16.md`. They are not built into the site. A scheduled routine writes one each Sunday ([`ROUTINE.md`](ROUTINE.md)), and once Parallax passes it a GitHub Action sends it to every subscriber through Buttondown. How it works: [`docs/NEWSLETTER.md`](../docs/NEWSLETTER.md). Mercury's guide: [`.claude/skills/add-content/agents/mercury.md`](../.claude/skills/add-content/agents/mercury.md). Start from [`TEMPLATE.md`](TEMPLATE.md).
