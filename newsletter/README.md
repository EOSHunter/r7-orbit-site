# Newsletter issues

Mercury's weekly issues, one Markdown file per issue, named by the day it is sent: `issues/2026-11-16.md`. They are not built into the site; Hunter pastes each one into Buttondown and sends it from there. How it works: [`docs/NEWSLETTER.md`](../docs/NEWSLETTER.md).
