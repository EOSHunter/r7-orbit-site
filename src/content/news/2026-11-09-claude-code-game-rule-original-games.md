Anthropic has loosened a rule in Claude Code that was turning down game projects. Addy Osmani, a member of Anthropic's technical staff ([Tom's Hardware](https://www.tomshardware.com/tech-industry/artificial-intelligence/anthropic-loosens-game-restrictions-claude-will-now-offer-to-build-original-game-in-same-genre-if-asked-to-copy)), said on Nov 4, 2026 that the rule is updated in Claude Code 2.1.317 ([Addy Osmani on X](https://x.com/addyosmani/status/2117848568535106001)).

> [!NOTE]
> From Claude Code 2.1.317 you can name an existing game to describe what you want, and Claude should build an original game in that genre. If you ask for a copy of the original, it offers to build something similar instead ([Addy Osmani on X](https://x.com/addyosmani/status/2117848568535106001)).

## What happened

Anthropic had added a short rule to Claude Code's prompt for Opus 5.5 to steer Claude away from recreating specific existing games. Osmani wrote that the rule also kicked in when people named a game only to describe the mechanics they wanted, so Claude Code pushed back on projects it should have built ([Addy Osmani on X](https://x.com/addyosmani/status/2117848568535106001)).

> [!POST] Addy Osmani · @addyosmani · X · Anthropic · 2026-11-04 · https://x.com/addyosmani/status/2117848568535106001
> You can name a game to describe what you want…

In an Oct 30, 2026 reply quoted in the same post, Osmani said the rule was two sentences, added because using Claude to infringe IP is against Anthropic's usage policy ([Addy Osmani on X](https://x.com/addyosmani/status/2117848568535106001)). Tom's Hardware links the original block to a rise in AI-assisted cloning and reverse engineering of games, including people who reverse engineered demos from small developers and threatened to release AI-finished copies unless paid ([Tom's Hardware](https://www.tomshardware.com/tech-industry/artificial-intelligence/anthropic-loosens-game-restrictions-claude-will-now-offer-to-build-original-game-in-same-genre-if-asked-to-copy)).

## Why it matters

Under the old rule, naming a familiar game to explain its mechanics was enough to get a game project turned down. Under the new one, the name describes the genre, and only a request for a copy gets the offer of something similar. Osmani said Anthropic wants Claude to help with original work and to "protect your work if someone else tries to copy it", and asked people to report cases where Claude turns down work that is theirs ([Addy Osmani on X](https://x.com/addyosmani/status/2117848568535106001)).

The Claude Code changelog entry for 2.1.317 does not mention the change ([Claude Code changelog](https://github.com/anthropics/claude-code/blob/main/CHANGELOG.md)). Osmani's post is the only statement from Anthropic I could find.
