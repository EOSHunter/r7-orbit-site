Anthropic said on Oct 22, 2026 that it is donating Agent Skills, the open standard for giving AI agents knowledge and workflows for specific tasks, to the Agentic AI Foundation (AAIF) ([Anthropic](https://www.anthropic.com/news/donating-agent-skills-to-the-agentic-ai-foundation)).

> [!NUMBERS] Since the standard was published in December 2025
> - **70+** agent platforms have added Agent Skills
> - **1 million** skills published
> - **Nearly 280 million** skill installs
>
> Source: [Anthropic](https://www.anthropic.com/news/donating-agent-skills-to-the-agentic-ai-foundation)

## What happened

The platforms that have added it include ChatGPT, Cursor, GitHub Copilot and VS Code ([Anthropic](https://www.anthropic.com/news/donating-agent-skills-to-the-agentic-ai-foundation)). A skill is a folder with a SKILL.md file that teaches an agent a task or a subject, plus any scripts or reference material it needs. Along with the standard, Anthropic is giving the AAIF the Agent Skills name and logo, the GitHub organization and the agentskills.io domain ([Anthropic](https://www.anthropic.com/news/donating-agent-skills-to-the-agentic-ai-foundation)).

Engineers from Anthropic, Google, OpenAI and other companies will maintain the standard as individuals, with David Soria Parra and Mahesh Murag as lead maintainers. The proposed roadmap has versioned releases, a formal proposal process, and security guidance for people who write and install skills ([Anthropic](https://www.anthropic.com/news/donating-agent-skills-to-the-agentic-ai-foundation)).

## Why it matters

Anthropic writes: "We're committed to keeping Agent Skills open, community-driven, and vendor-neutral." Anyone can keep using the standard or contribute to it without joining the AAIF; the specification is at [agentskills.io](https://agentskills.io/specification) ([Anthropic](https://www.anthropic.com/news/donating-agent-skills-to-the-agentic-ai-foundation)).

The announcement gives no date for the first versioned release.
