# R7 Orbit site decisions

- **2026-10-03 — Build a static content site.** Astro, MDX collections and `src/content.config.ts` define posts and pages; the build adds Pagefind search (`package.json`, `pagefind.yml`).
- **2026-10-03 — Keep content types explicit.** Blog, news, vlogs, projects and repositories have distinct collection data and routes (`src/content.config.ts`, `src/pages/`).
- **2026-10-04 — Let editors draft articles through Git (expanded 2026-10-05).** The bundled Decap CMS at `/admin/` first wrote blog MDX; it now writes all five post kinds, About and site settings. Locally it uses a file proxy; deployed editing uses GitHub authentication and editorial pull requests. Drafts and future-dated posts stay out of published output (`README.md`, `src/admin/config.ts`, `src/content.config.ts`). The authentication Worker must be deployed/configured separately.
- **2026-10-04 — Share article components between authored pages and the editor.** MDX blocks under `src/components/article/` match the insert controls in `src/admin/blocks.ts`; `docs/ARTICLE_COMPONENTS.md` documents the supported props.
- **2026-10-05 — Expose editorial content as checked sections.** Shared section definitions and conversion code under `src/lib/sections/` and `src/lib/sections-to-content.ts` support editable page and post layouts; `docs/SECTIONS.md` is the authoring guide. Content schemas and tests reject invalid combinations.
- **2026-10-05 — Derive game and author pages from content.** Projects with a Play URL appear on `/games/`, with embed policy in `public/_headers`; author records drive profile pages (`src/pages/games/`, `src/pages/authors/`, `README.md`).
- **2026-10-05 — Keep publishing controlled by Git and build checks.** `src/admin/config.ts` uses editorial workflow outside local mode; `docs/PUBLISHING.md` and `docs/DEPLOY_CLOUDFLARE.md` describe review, scheduled posts and Cloudflare Pages. These are repository configuration and instructions, not evidence of successful production deployment.
