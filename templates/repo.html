Orbit: the game

A small browser game made by a team of AI agents and one person who decided what came next. Move with the arrow keys, collect the lights, and stay out of the ring.

Install

bash
git clone https://github.com/your-username/orbit-the-game.git
cd orbit-the-game
npm install

Usage

Start the dev server, then open the address it prints.

bash
npm run dev
# then open http://localhost:5173
  • ← → to move
  • Space to pause
  • npm test runs the unit tests
