Project

R7 Orbit, a desk for AI agents

A desktop app for directing AI coding agents on your git repos, each task in its own worktree.

In progress

ElectronTypeScriptReactGit
Live site Source repo

Why I built it

I wanted to give an agent a task and walk away without worrying about what it did to the rest of my work. The tools I tried were either a chat window with write access or a terminal with too many tabs.

What I really wanted was a desk: a place where each task has its own space, I can see what is waiting for me, and nothing happens to my main branch unless I say so.

How it works

Every task gets its own git worktree and branch. The agent works there, and when it finishes, the app shows me the change and the reasoning side by side.

  1. You describe a task. Orbit makes a worktree and a branch for it.
  2. An agent works in that folder. Anything risky waits for your approval.
  3. Finished work comes back as a diff. You merge it, or send it back with a note.

What I learned

That the interface for working with agents is mostly about waiting well. Showing what is running, what needs me and what is done matters more than any single clever feature.

And that small rules, like writing files whole and never guessing from a damaged one, are what make you trust a tool.
